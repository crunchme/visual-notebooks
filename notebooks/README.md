# CrunchME visual notebooks

These notebooks are the public, reproducible analysis sources for selected CrunchME visuals.

Before running a notebook, replace any `your.email@example.org` value with a valid contact email
for PubMed Entrez. Do not commit personal contact details, NCBI API keys, Drive paths, access
tokens, or other credentials. If a notebook needs the Brutel font for chart rendering, upload only
appropriately licensed font files when prompted; it does not depend on a mounted Google Drive.

The checked-in workbook outputs are historical analysis snapshots. Regenerated charts and
downloadable datasets must be reviewed and committed alongside the notebook change before the
corresponding visual is redeployed.
